## 🎨 Dizayn va Texnologiyalar
- **Ranglar palitrasi:** To'q ko'k (Royal Navy / `#0A152D`) va Oltin (Imperial Gold / `#D4AF37`) premium mavzusi.
- **Texnologiyalar:** Toza HTML5, Vanilla CSS3 (zamonaviy glassmorphism, mikromimika va animatsiyalar) va sof JavaScript (ES6+).
- **Tovush tizimi:** Web Audio API asosida (hech qanday tashqi audio fayllarsiz ishlaydi).
- **Moslashuvchanlik (Responsive):** Kompyuter, noutbuk, planshet va smartfonlar ekraniga to'liq moslashgan.

## ⚡ Test Rejimlari:
- **Tezkor Test (10 ta savol):** 10 daqiqa vaqt bilan bilimlarni tez sinovdan o'tkazish.
- **Standart Test (20 ta savol):** Eng maqbul format (20 daqiqa).
- **Kengaytirilgan Test (30 ta savol):** Chuqur bilimlar sinovi (30 daqiqa).
- **Katta Sinov (50 ta savol):** Yakuniy nazorat va olimpiadalarga tayyorgarlik (45 daqiqa).
- **Bo'limlar bo'yicha mashg'ulot:** Har bir bob bo'yicha alohida amaliyot.
- **Imtihon rejimi:** Jonli sanaydigan taymer, rasmiy baholash mezoni (5, 4, 3, 2).
- **Mashg'ulot rejimi:** Har bir javob belgilanganda darhol to'g'ri/noto'g'ri ekanligi va darslikdan batafsil izoh chiqadi.
- **Xatolar ustida ishlash:** Test yakunida faqat xato qilingan savollardan iborat qayta test topshirish imkoniyati.
